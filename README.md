# Study MBBS Abroad Landing Page
A responsive landing page designed to showcase MBBS programs in various countries and capture potential student leads. This project was developed as part of the Front-End Development Intern application for University Insights.
## 🎯 Project Overview
The landing page serves as an informational and lead generation platform for students interested in pursuing MBBS abroad, featuring:

- Interactive hero section with compelling call-to-action
- Comprehensive information about MBBS programs in different countries
- Streamlined admission process overview
- Lead generation form with validation
- Analytics integration for performance tracking

## 🌟 Key Features

- Responsive design that works seamlessly across all devices
- SEO-optimized content structure
- Fast loading and optimized performance
- Country-specific program information

## 🛠️ Technical Stack

Frontend:

- HTML5
- Tailwind CSS

### Hero Section

- Banner with primary CTA

## 🚀 Setup Instructions

1. Clone the repository: <br>
```https://github.com/yourusername/mbbs-abroad-landing```

2. Install Tailwind CSS:

- Add Tailwind via CDN in your HTML file: <br>
```<script src="https://cdn.tailwindcss.com"></script>```

3. Open the project:

- Use a live server extension in VS Code
- Or open the HTML file directly in a browser
